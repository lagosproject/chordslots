## Context
`generateChords` (`core/include/chordslots/Generator.h`) runs **4 Gibbs sweeps** over a ring of
≤ 16 slots, with a softmin at a fixed `temperature` (0.012; `rerollSlots` uses 0.004). The
bass inversion is chosen afterwards by a separate circular DP (`generateBassLine`), and
the voicing by a third pass (`voiceAll` + `optimizeVoiceLeading`). The cost is
`slotCost` = target error + complexity/outside price + A-B-A penalty (uses `prev2`) +
`transitionCost(prev→cand)` + `transitionCost(cand→next)`. Phrase repeat (AA′) ties slot
j with j+h. Locks: `slotChordIsFixed`, `slotCandidates` (root/colour layer locks), slot
locks.

## P5.1 — exact ring sampling (commit "Generator: exact forward-filtering backward-sampling on the ring")
- Replace the Gibbs sweeps with **forward-filtering / backward-sampling (FFBS)** on the
  ring. Use the first-order part of the cost only: unary = the target, complexity and
  outside terms of `slotCost`; pairwise = `transitionCost(a→b)`, scaled exactly as in
  `slotCost` today (each transition counted once, including the wrap n−1→0).
- Ring handling: compute slot 0's exact marginal by summing over its states (K ≤ a few
  hundred, n ≤ 16, so K²·n is fine), sample slot 0, then run FFBS conditioned on it.
  Work in log space (log-sum-exp).
- Temperature: probabilities ∝ exp(−cost / T). Keep T = 0.012 for Roll and 0.004 for
  `rerollSlots` so the feel is comparable.
- Locks: a fixed slot has one state; layer locks restrict the state set; AA′ tied pairs
  share one variable (sample the pair as one node whose unary is the sum of both slots'
  unaries, with pairwise terms on both sides).
- Tests: on a 3-slot ring with a hand-computable cost, the sampled frequencies over 20,000
  draws match the exact distribution (χ² or max abs error < 0.01); determinism (same seed
  → same output); locks respected; AA′ respected.

## P5.2 — A-B-A as a Metropolis–Hastings correction (commit "Generator: A-B-A penalty via MH correction")
- The A-B-A term is second-order. After FFBS, run a few (e.g. 2n) single-slot MH
  updates whose target is the full `slotCost` (including the A-B-A term) and whose
  proposal is the exact conditional of the first-order model. Accept/reject correctly.
- Test: the A-B-A-B rate (eval `ababPct`) is not higher than the P4 baseline.
