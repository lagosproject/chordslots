## Context
`tensionOf` (`core/include/chordslots/Metrics.h`) is static per chord symbol: dissonance of the
chord **type** in close position at middle C (`typeRoughness`), TIV distance from the key,
and a function weight (`bVII` is scale-dependent since P1.3). It ignores the real voicing
and the previous chord. For listeners, tension depends a lot on context.

## P6.1 — static tension from the real voicing (commit "Metrics: roughness from the actual voicing")
- In `updateActuals`, compute roughness from the slot's **actual voicing notes**
  (`roughness(notes, n)`, normalised per note pair or per note; calibrate so the
  distribution over the eval baseline progressions keeps a similar range to today's).
  Keep the type-level estimate only for candidate preselection.
- Test: the same chord voiced as a low cluster measures tenser than a spread voicing.

## P6.2 — contextual term (commit "Metrics: contextual tension from the previous chord and key")
- Implement the Spiral Array tension measures (Herremans & Chew, "Tension ribbons", 2016):
  **cloud diameter** (the spread of the chord's notes in the spiral array), **cloud momentum**
  (the distance between the centres of effect of the previous and current chord), and
  **tensile strain** (the distance from the chord's centre of effect to the key's).
  References to check the numbers against: midi-miner (github.com/ruiguo-bio/midi-miner)
  and partitura's `musicanalysis.tonal_tension`. Port the formulas to C++ (no
  dependencies), with unit tests that reproduce 3–4 values computed with one of those
  libraries (write the expected values in the test with a note on how you got them).
- New tension = w1·static (P6.1) + w2·tensile strain + w3·cloud momentum (to the previous
  chord, ring-wrapped). The momentum term is pairwise, so it goes into the P5 pairwise
  cost through the chord's measured tension. Expose the weights as named constants.

## P6.4 — listening protocol (user involvement: do not skip)
- Add `chordslots-cli listening-test --out dir/` that writes 20 short MIDI files (4-chord

- Compute the Spearman correlation of the ratings with the old static model and with the
