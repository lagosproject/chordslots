## P8.3 — AU MIDI FX for Logic (commit "Build: AU MIDI effect variant")
- Logic cannot route MIDI out of an AU instrument (`kAudioUnitType_MusicDevice`) to
  another track. Add a second plugin target (e.g. "ChordSlots MIDI FX") with
  `IS_MIDI_EFFECT TRUE`, `AU_MAIN_TYPE kAudioUnitType_MIDIProcessor`, sharing all sources.
  The preview synth stays silent or is removed in that variant.
- `auval -v aumi …` in macOS CI.
- **Manual check (user):** in Logic, insert it as a MIDI FX on a software-instrument
  track; Roll; the instrument must play the chords. Ask the user to confirm.
