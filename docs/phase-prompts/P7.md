## P7.1 — Harmonize my melody
- The editor already has "Analyze MIDI" (`PluginEditor::analyzeMidi`, which loads a `.mid`).
  Add "Harmonize melody": load a MIDI melody (the track with the most notes above C4, or
  the user picks one) and quantise it to the loop length.
- Per slot, build a weighted pitch-class profile of the melody: weight = duration ×
  metric weight (strong beats per `Meter::strongOffsets` × 1.5).
- New `slotCost` term `melodyCost(chord, profile)`: chord tone = 0; an available tension
  (9, 11 on minor, #11 on major, 13) = low; an avoid note = high (natural 4 over a major
  3rd, b9 over the root of a non-dominant chord, natural 7 over a dominant). A weight knob
  `MELODY FIT` (0 = ignore).
- Optional: make the top voice of the voicing follow the melody note on the slot's
  downbeat (Piano/Close/Drop styles).
- Tests: on "Twinkle Twinkle" in C (hand-written note list), the default roll uses only
  chords whose avoid-note count is 0 on strong beats; the cost is monotonic in the weight.

## P7.2 — bass patterns on Ch 2
- Patterns: Sustain (today), Octave pump (root/octave 8ths), Offbeat 8ths, 808 legato
  (one note per slot with a "glide" flag: overlapping note-offs so mono synths slide),
  Walking (quarter notes: root, approach tones chromatic/diatonic into the next slot's root).
- Bake into `PlayData` exactly like comping (fixed arrays, no allocation, bounded event
  list, strum not applied to the bass). Export parity test for every pattern × split on/off
  × 60/120/200 BPM, plus a no-stuck-notes test.

## P7.3 — Song mode
- A chain of up to 16 entries (variation A–D + transpose in semitones) per project,
  persisted in the state. The playback follows the chain when "Song" is on; quantised
  switching uses the existing machinery.
- "Drag Song" exports the whole chain as one MIDI clip (chords + bass tracks, markers per
  section).
- Tests: the exported song length = the sum of the variation lengths; transposition is
  applied; state round-trip.

## P7.4 — Chord names in exported MIDI
